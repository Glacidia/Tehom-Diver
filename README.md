  Therefore I decided to make my own game just to re-experience the feeling of playing it.

# GameType
  A rougelite Top-Down Shooter game, players can gain exp through elimanating enimes. When you gain enough exp, you level up and gain a chance of choosing one of the four upgrade cards.
  Each Boss would drop unique upgrade core after you kill them, each boss core has different ability which related to them. The game will keep spawning minions and Bosses, so just dodge, survive, killing, and leveling up.
