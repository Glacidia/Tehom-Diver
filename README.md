# Tehom-Diver
A rougelite Top-Down Shooter game  (VIBE CODING)
# Warning 
  Over 90% of the contents are created through vibe coding, because I have no coding ability and feeling lazy.
  Although you can still complain about the ai slop, because im also pissed off by this agent too.
  Yes, it is inspired by diep.io (2016 Ver.), because i couldn't reconize it while I go back and play it.
  Therefore I decided to make my own game just to re-experience the feeling of playing it.

# GameType
  A rougelite Top-Down Shooter game, players can gain exp through elimanating enimes. When you gain enough exp, you level up and gain a chance of choosing one of the four upgrade cards.
  Each Boss would drop unique upgrade core after you kill them, each boss core has different ability which related to them. The game will keep spawning minions and Bosses, so just dodge, survive, killing, and leveling up.

## 下載與開始遊玩

1. 開啟此倉庫的 **Releases**，選擇要下載的版本。
2. 在 **Assets** 下載 `Tehom-Diver-Player-Ver.0.162.zip`。GitHub 自動產生的 `Source code` 壓縮檔不是玩家包。
3. 將 ZIP 完整解壓到一個資料夾；不要直接從壓縮檔內開啟遊戲。
4. 用最新版 Chrome、Edge 或 Firefox 開啟 `Tehom-Diver-Play.html`。

不需安裝 Node.js 或其他開發工具。請保留包內 `docs/` 與 `dist/` 資料夾，讓圖鑑正常使用。桌面版以鍵盤及滑鼠操作；手機與觸控操作尚未驗證。
